# FIFA Galaxy

Site inicial para divulgar uma coleção de figurinhas digitais de jogadores desenhadas pelo autor do projeto.

## Como usar
1. Abra `index.html` no navegador.
2. Troque os textos "JOGADOR", "SEU DESENHO" etc. pelos dados reais.
3. Para colocar suas artes, você pode substituir os blocos `.art-placeholder` por imagens.
4. Edite cores e identidade visual em `style.css`.

O projeto é apenas um template visual e não afirma qualquer vínculo oficial com a FIFA.

## Fundo
A imagem `galaxy-background.jpeg` é usada como fundo fixo, com camadas escuras e translúcidas para preservar a leitura.
